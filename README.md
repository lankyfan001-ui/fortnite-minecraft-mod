# -----------------------------------------------------------------------------
# Fortnite Forge Mod
# -----------------------------------------------------------------------------
# This repo is intended for a Forge 1.20.1 mod inspired by Fortnite cosmetics and
# POI/structure concepts. The current starter project focuses on the registry and
# the first armor/outfit system.

## Current status
- Forge 1.20.1 project scaffold created
- Core mod entry point added
- Fortnite-inspired armor registry implemented
- Placeholder item naming and structure prepared for future models/textures
- Next planned work: POI generation, bosses, and visual polish

## Running locally
1. Install JDK 17
2. Open the project in IntelliJ IDEA or VS Code with Gradle support
3. Run the Forge client/server Gradle tasks
4. Use `./gradlew genIntellijRuns` if needed for IDE support

## File organization
- `src/main/java/com/lankyfan/fortnite/` - mod code
- `src/main/resources/assets/fortnite_overhaul/` - item models and language files
- `src/main/resources/META-INF/` - mod metadata

## Notes
This starter is intentionally designed as a clean base for expanding into:
- Fortnite outfit armor sets
- Back bling and cosmetics
- POI generation
- NPCs / bosses
- UI overlays and location banners
